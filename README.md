## Internal use
- A web application containing forms to add teachers, students, and courses;

- Implement the logic to associate courses with teachers and students;

- Ensure that each student can be associated with a maximum of 4 courses;

- List all courses, teachers, and students in the interface;

- Allow editing and removal of records.

## Description

This repository is dedicated to formalizing a complete API in Nodejs, implemented with the following technologies:

### Fastify
- Fast approach for large numbers of HTTP requests; 

- Native support for TypeScript; 

- Flexible routing; 

- Plugin insertion to intercept routes; 

- Register plugins, or reuse third-party plugins;

- Low resource consumption.

### Prisma
- Prisma's schema makes it easy to visualize and structure your database clearly;

- It automatically generates typed queries and offers tools such as Prisma Studio for quick data inspection;

- Strong typing and automatic type generation;

- Standardized and easy-to-manage migrations.

### TypeScript
- Greater robustness and fewer errors;

- Facilitates the creation of large and complex code bases, allowing for clearer architecture and simpler maintenance;

- More powerful development tools;

- Allows you to define types for variables, functions, and objects, making the code more predictable;

- Advanced language features, such as decorators, enums, generics, and interfaces;

- Compiles to standard JavaScript, allowing you to use TypeScript in any JS environment while ensuring more robust final code.
